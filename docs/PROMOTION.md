# QuotaBar · 多语言宣传文案 / Multilingual promotional copy

九种语言共用同一个定位：把多个 AI 服务的额度与余额放到 Mac 菜单栏，减少来回查找用量页面的负担。

这些文案描述介绍文档的语言，不代表应用界面已经支持九种语言。功能边界、系统要求和代码来源以仓库文档为准；ZCode 未实现，Codex / GPT 指本机 Codex 账号的用量，DeepSeek 显示余额。当前提供源码，未发布本定制版安装包。

产品来源：MyKWK 原创的本机 Kimi 工具与产品设计，结合后续引入的 Chiloh / chilohwei 社区代码及我们新增的功能。分享时保留仓库内的来源与许可说明。见 [项目沿革](ORIGINS.md)。
